## Acrónimos

[TODO] Definir cada acrónimo. Lista inicial (completar/depurar conforme se redacta):

- **CA** — Autoridad de Certificación (Certificate Authority).
- **CWE** — Common Weakness Enumeration (catálogo de debilidades de software).
- **DMZ** — Zona desmilitarizada (red intermedia entre la red externa y la interna).
- **HIDS** — Sistema de detección de intrusiones basado en host (Host-based IDS).
- **IaC** — Infraestructura como código (Infrastructure as Code).
- **IDS / IPS** — Sistema de detección / prevención de intrusiones.
- **KPI** — Indicador clave de rendimiento (Key Performance Indicator).
- **MTTD** — Tiempo medio hasta la detección (Mean Time To Detect).
- **mTLS** — TLS mutuo (autenticación de cliente y servidor con certificados).
- **NIDS** — Sistema de detección de intrusiones basado en red (Network-based IDS).
- **ODS** — Objetivos de Desarrollo Sostenible.
- **PEP** — Punto de aplicación de políticas (Policy Enforcement Point).
- **RCE** — Ejecución de código remota (Remote Code Execution).
- **SIEM** — Gestión de información y eventos de seguridad (Security Information and Event Management).
- **SOAR** — Orquestación, automatización y respuesta de seguridad.
- **SSTI** — Inyección de plantillas del lado del servidor (Server-Side Template Injection).
- **TLS** — Seguridad de la capa de transporte (Transport Layer Security).
- **ZT / ZTA** — Zero Trust / Arquitectura Zero Trust.
