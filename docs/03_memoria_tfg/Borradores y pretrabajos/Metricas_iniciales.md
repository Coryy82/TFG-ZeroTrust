# Métricas iniciales
Para comparar el escenario Perimetral vs Zero Trust mediré:
Tiempo de Detección (TTD): Segundos hasta que el sistema alerta.
Profundidad del ataque: Número de nodos internos alcanzados.
Tasa de bloqueo: Éxito o fracaso de la contención automatizada.

(Estas métricas se propusieron al inicio del todo para aprobar la idea del TFG con el tutor)
